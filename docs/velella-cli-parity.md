# Velella CLI 与 Orca CLI：范围和验收

用户目标：继续补齐 Orca CLI 的功能差距，让自己的 Velella CLI 能完成日常鱼群管理。名称统一为 Velella CLI，入口 `velella-cli`。基线为本机 Orca 1.4.243 帮助/版本指南与 Velella CLI 0.1.0；这不是对 Orca 每个接口的运行验收。

当前关键路径：复用已有运行时接口形成完整管理路径；新 SSH 客户端必须确认准确服务器和目录、拒绝跨目标回退；浏览器必须由真实桌面桥和页面身份授权。现有任务/编排引擎保持原有检查，不通过升级生产后台来隐藏接口缺口。

本轮完成定义：命令可发现，参数与后端匹配，写入不确定不重放，工作区/Git/终端/自动化/资源/浏览器有真实或明示夹具范围的闭环验证；固定 CLI 安装后只读在线检查通过，生产会话保持。实现、开发验证、独立测试、技术验收、集成、CLI 安装、当前在线与真实业务 UAT 分别记录在本轮 artifacts 回执。

| 功能族 | 本轮实现范围 | 完整对齐仍有的差距 |
| --- | --- | --- |
| 项目/工作区 | 导入、基准/准备策略、元数据、归档恢复、版本化布局 | 项目删除、工作树回收、端口发现未接入 |
| 终端 | 创建、读写、等待、逻辑屏幕、恢复、标签改名、原生会话分屏；switch 精确选择本机桌面的项目/标签/分屏并确认焦点 | 任意应用窗口控制、所有 TUI 画面的兼容性未全量验证；SSH 桌面切换不支持 |
| 任务/编排 | 沿用创建、反馈、验证、停止和 v2 编排控制；公共 collab 接入现有会话成员、消息、工作和验收回执 | 与 Orca mailbox/worker 协议不兼容；四 CLI 真实业务 UAT 仍单独验收 |
| 文件/Git | 工作区文件读写搜索、并发检查、改名删除、本地暂存和提交 | CLI 不做推送、发布或 Issue/PR 外部关联 |
| 自动化 | 已安装版：创建/保存、禁用、立即运行、可恢复移除、恢复后禁用、完整历史分页；默认创建为禁用 | 真实模型执行及业务日程 UAT 未执行；移除保护未结束任务，恢复需审阅保存才能启用 |
| SSH | 配置、检查、本机 SSH 交互终端；独立 SSH 远程 RPC | 真机目标/认证与长期断线恢复另验；不借用 Electron 的连接 |
| 技能/MCP/账号 | skills bundled/get 离线内置指南和版本发现；原生 provider 检查、用户技能读取、本机技能包预览/安装/备份移除/恢复、MCP 来源及工具确认；Codex stdio MCP 原生配置预览/安装/移除/原样恢复 | 多账号隔离/切换、远端技能管理、Claude/HTTP 等通用 MCP 安装未实现；原生 Agent 实际加载另验 |
| 浏览器 | 页面生命周期、导航、AX 快照、引用动作、PNG、控制台/网络元数据；forget 同步清理活动标签和关闭历史，已通过真实桌面五组验收 | 不提供任意 eval、跨浏览器配置档或原生桌面控制；真实第三方站点业务 UAT 另验 |
| 会话搜索 | 工作区代码文件搜索；PTY 录制搜索；新增本机 Codex/Claude 原生 JSONL 对话搜索，按准确工作目录限定，支持显式工具范围 | 原生搜索为有界扫描，无持久全文索引；不含归档、远端和 Claude 子代理记录；终端录制与原生对话仍分别标记 |
