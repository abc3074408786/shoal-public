# Agent 内容设计三版

2026-11-01 用户选择左侧导航 A，同时认为当前 Agent 页面难看。本轮先按 A 接入分类导航，再提供右侧 Agent 内容三版真实交互样本。最终可感知结果：比较工具列表、工具卡片、工具与详情三种结构，能选择默认工具、切换启用、查看完整设置上下文。验收：相同七个真实工具、字体、Logo，保留已选的 02 默认 Agent 下拉框；结构差异明确；启用/默认只在本页 React 内存中，不调用后台、不保存真实偏好。正式 Agent 内容仍待用户选择。

设计技能：用户提供的 Emil Design Foundations 和 Surfaces。避免上一版大片空行、整行蓝色默认高亮、过多次要信息、反复图标容器；用对齐、分组和较克制的面区分主要任务。现有字体和品牌为已确定约束，不重新选择字型或 Logo，不放装饰插画。状态不编造检测结果：卡片/详情均标为未检测，重新检测按钮在设计演示中禁用并明确说明，避免假在线状态。既有启动程序名直接取真实 agentCatalog。

01 紧凑工具列表：单个轻表面容纳七个工具，名称、命令、启用开关按列对齐，默认用名称旁短标签表示，不整行染色。适合频繁管理入口、期望轻量密度的人。02 双列工具卡片：每个工具有清晰 Logo、名称、启动命令，启用在右上，设为默认在卡片底部；选中只用轻描边，不用强色大底。03 工具与详情：左侧为工具选择，右侧展示所选工具、启动命令、检测状态与显示入口开关，并提供设为默认动作；工具选择与默认选择相互独立，不把点选详情误当默认设置。

比较页三列展示内容区，完整上下文固定采用 A 导航，右侧有独立滚动区。桌面约 1440×1000，小屏纵向对比，完整设置页缩为 62px 分类栏，表格/控件自动换行。基于真实默认选择解析规则：禁用默认项回退自动，设为默认会启用该工具。权限页仅显示原有模式目录，未重做权限规则。最终审美接受由用户选择；本地开发检查与实际桌面安装后验收分开。
