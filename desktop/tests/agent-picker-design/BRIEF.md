# 默认 Agent 下拉框设计备选

用户最终可感知结果：能直接看到三版有明显结构差别的下拉菜单，体验展开、收起、悬停和选择，结合现有设置界面决定采用哪版。总体验收标准：真实 Logo 正确显示，沿用现有 Geist / 微软雅黑字体、灰白底和蓝灰强调色；每版完整包含自动选择、空白终端及七个 Agent；选择后按钮更新，键盘方向键和 Enter 可操作，Escape 收起，点击外部收起；小屏无横向溢出，减少动态偏好有效。当前关键路径是完成隔离预览、浏览器实际查看并给用户展示。选择正式设计和集成正式界面属于后续用户决定，本次不改已冻结权限功能和已安装程序。

使用场景：开发者在 Velella 设置的 Agent 页选择新终端的默认启动工具。选择频率较低，但用户需要快速认出不同工具，并清楚区分自动选择和直接指定工具。不是营销页，不需要摄影、插画或额外品牌装饰。核心图像就是源码里已经确认的七个 Agent Logo，直接复用 AgentLogo 组件。所有选项均使用真实目录名称和启动命令，终端和自动选择使用现有 Lucide 图标。检测状态不在备选菜单里伪造。

三版同一内容、同一字体及色板，只改变菜单的信息组织。01 紧凑列表：每行一个 Logo、名称及右侧选中勾号；自动选择和空白终端与 Agent 分隔；单行密度适合较窄的设置控件。02 双列面板：自动选择、空白终端位于面板顶部独立区域，七个 Agent 采用双列布局，各自包含图标、名称与命令；更容易扫视 Logo，垂直高度更短，但面板更宽。03 说明列表：顶部展示当前选择摘要，列表以两行文字展示名字和实际启动命令；自动与终端给出简短效果说明；适合希望选之前理解具体行为的人。

统一预览格式：同一个响应式比较页，桌面约 1440×1000 三列并排，独立 HTML 提供 860px 设置窗口上下文。比较页只截取设置内核心区域，避免把整个设置窗口缩得过小；独立版保留侧栏、默认选择行和 Agent 清单。以 14px 选项名称、12px 辅助信息、38–52px 行高建立层次。紧凑版 280px，面板版 360px，说明版 320px，最大尺寸始终受视口约束。

采用 Emil surfaces 的层叠透明阴影与外大内小圆角，使用动画技能的触发点原点、短距离位移、短时淡入及减少动态分支。菜单淡入 150ms，位移最多 3px，缩放最低 .985，无弹簧、无列表逐项飞入、无持续装饰动效。用户此前对动效不满，动作应只解释展开关系。键盘导航不使用动画。实现只在本预览 React 状态中切换，不访问运行时、不保存偏好、不触碰真实终端。

验收分层：源码与预览实现、浏览器交互检查、视觉由用户选择。技术检查不能代替用户审美验收。选定后再记录 direction-approved.md 并将所选菜单接入原有 draft/save 流程。
