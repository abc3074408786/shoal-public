# 设置分类导航三版样本

用户指出设置侧栏截图，要求 Agent、权限几个样本，并要求使用已经提供的设计技能。本次最终可感知结果：三版可直接比较、可点击切换 Agent/权限，且可进入完整设置内容上下文的设计样本。验收：字体、灰白色与既有 Agent Logo 沿用；选中、悬停、键盘焦点可见；图标与名称真实一致；三版结构有实质区别；没有写入真实偏好、后台、安装目录或终端。关键路径是制作隔离样本并用浏览器实际展示。正式导航待用户选定后再改。

采用用户提供的 Emil design-foundations 与 ui-polish：信息层级靠对比与间距建立；统一图标线重；选中不改变字重导致抖动；hover 只改变背景/颜色/阴影，120ms，无多余位移动效；独立键盘 focus；减少动态偏好关闭过渡。用户现有字体和品牌优先于重新选字体。导航项均保持至少 40px 高。当前只有 Agent、权限，不添加空设置分类、无效搜索或假的系统状态。主机信息只展示本机及偏好独立保存，不以绿色状态点假装在线验证。

A 轻量列表：沿用两项垂直列表，取消明显蓝色大底，使用白色轻选中面、蓝灰图标和微小选中点；普通项退后，适合当前克制的灰白风格。B 说明导航：两行选项显示名称与短用途，图标放入统一容器，当前项显示轻箭头；信息密度更高，面向首次使用者。C 窄图标栏：80px 导轨，图标与名称上下排列，主机信息折为带 tooltip 的监视器图标，释放横向内容空间。每项都保留可见名称及辅助名称，不依赖猜图标。

比较页统一舞台高度 590px，桌面三列，小屏纵向排列；完整上下文使用同一套右侧 Agent/权限内容，差别只在导航。右侧沿用已选的 02 双列默认 Agent 控件、真实目录名称及真实权限选项，所有调整只在 React 内存状态中，不保存。图片只需要已有 AgentLogo，导航图标用已有 Lucide，不需要生成装饰图或重新下载商标。宽视口固定侧栏、内容独立滚动；小屏上下文缩窄侧栏并让控件换行。

本次不替换正式设置页、不部署。视觉选择属于用户，开发检查不替代用户的最终审美判断。
