# Velella 界面原型

解压整个 ZIP，双击 `Velella-Prototype.exe`。启动器会打开本机浏览器中的原型目录。预览期间请保留启动器窗口，关闭窗口即可结束预览。如果浏览器没有自动打开，请把启动器显示的地址复制到 Edge 或 Chrome。

从 **进入工作台** 可以打开示例项目，使用工作台的正常导航操作。从 **打开示例项目** 可以直接浏览终端、文件、代码、Git 和浏览器标签。编排、自动化、插件、权限、加载和异常状态也有单独入口。

这是前端原型，使用当前 Velella 源码、项目现有的交互夹具和模拟数据。模拟终端、文件和设置用于演示，实际 CLI、SSH、账号登录、外部连接和内置浏览器网页由桌面产品提供。重新打开页面可恢复初始示例。在安装的 Velella 中验证真实运行时及业务流程。

启动器使用本机回环地址，静态页面、编辑器、字体和图标均随包提供，预览可离线使用。
