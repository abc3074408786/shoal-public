# 技能中心

按已确认方案交付本机内置插件，统一管理项目与全局技能；本地/Git 导入、预览、分发、更新、回滚、普通终端兼容启动与编排显式快照。工作区各自隔离，保持账号目录、权限和已有会话边界。

完成定义：固定候选通过文件生命周期、隔离、并发/中断恢复、UI 与编排测试；每个 Agent 的真实可用性单独验证。文件复制、提示提交与实际使用分开记录。缺失工具或账号时保持未验证，不自动安装或登录。开发候选不替换现用安装。

技术路线：复用 Rust 原生包校验/摘要/锁及备份约定，以持久事务日志发布副本；Electron 注册插件并调用同包 CLI；新增项目上下文能力查询保持旧接口兼容；非 Codex/Claude 的普通启动通过新 skill_prompt 字段核验 CLI help 后传独立 argv，禁止恢复时重放任务。
