# 关屏与合盖后继续运行所有 CLI

## 用户结果

在当前 Windows Velella 接电时启动任意原生 CLI，关屏、锁屏或在启用合盖运行配置后合盖，任务与原始输出持续推进；重新打开屏幕后继续原会话。覆盖 Agent 品牌、普通 shell、自动任务和旧 headless PTY，不依赖前端页面持续轮询。用户于 2026-11-15 同意缩小为仅接电运行：电池供电保留原睡眠策略。

## 范围

- Rust 会话实际存活且接电期间持有 Windows 系统保活请求；会话结束、启动失败、拔电或供电未知时释放，不要求屏幕保持点亮。多个会话互不撤销保活。拔电后的策略生效不等于模拟再次合盖或立即强制睡眠。
- 直接 hybrid SSH 执行入口补齐本机保活，远端主机仍由远端电源和进程策略管理，不声称本机保活保障远端不断线。
- 提供 Windows 配置脚本：默认只读检查；显式启用时备份当前电源方案及设置，只将接电合盖设为不操作、接电空闲设为不睡眠，电池设置不变；提供恢复。它是持续生效的系统设置，包括退出 Velella 后，不能伪装成仅在任务中生效。
- 配置保存原方案 GUID；恢复不得静默覆盖用户之后改变的设置或切换到其他方案。命令失败报告具体步骤及已改变的值，不伪报成功。
- 保留屏幕超时、锁屏、临界电量、温控、主动睡眠和关机行为；不得模拟键盘鼠标输入或关闭 Modern Standby。
- 不重启现有 CLI、修改账号与 CLI 配置或重写历史。本次验收以隔离候选为准；物理合盖与真实业务 UAT 单独记录。

## 验收

1. 接电时任意适配器的存活 PTY 都持有保活；正常退出、失败和停止后释放。保留已结束的历史对象不能继续保活；电池和未知供电不能持有保活。
2. 多会话时结束其中一个，剩余会话的保活仍有效；无会话时不保活。
3. 保活请求不含保持显示器点亮、不触发输入、不改变会话日志与权限；请求失败可观察，不能报告成功。
4. 配置脚本默认无系统写入；启用、重复执行、失败、恢复和设置冲突有确定行为；恢复保护后续用户修改。
5. 原生隔离连续输出测试核对退出前后日志、会话身份和 Windows 请求。锁屏/关屏/接电合盖需记录供电方式、持续时间和输出连续性；电池测试确认原策略未改、无保活请求；未执行的物理测试明确未通过。

## 依据

2026-11-15 只读核查：当前设备支持 S0 Modern Standby（待机断网），当前 Silent 方案的接电/电池合盖均为睡眠，空闲睡眠均为 0 秒。不能把此前后台窗口调度验证当成电源验证。
