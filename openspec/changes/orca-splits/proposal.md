# Orca 式两层分屏

用户已选择“两种都要”：终端标签内部拆分，以及混合终端、文件、浏览器的工作台分栏。沿用唯一海雾前端。

总目标：用户能向右/向下连续拆分终端，拖动分界线和终端面板，拖标签到工作台边缘创建分栏；关闭后自动补齐，布局重开恢复，现有会话/输入/输出状态保留。

验收合同：旧单双栏兼容；至少四块混合嵌套布局；两层分隔线指针、键盘调整和持久化；标签/终端面板移动；终端展开/还原；关闭视图保留后台；切换标签及工作区后终端实例和消费偏移保留；错误/重复请求不重复新建终端；跨工作区 session、重复/悬空树节点被后台拒绝。真实组件浏览器夹具、Rust 持久化测试、构建、独立只读复核后冻结候选；集成/安装/原生验证单列。业务 UAT 由用户实际使用判断。

实现：Layout.tree 使用 pane id 叶子；Tab.terminalTree 使用 session id 叶子。字段可缺省，旧 axis/ratio 保留以读取旧布局。共享 SplitSurface 用扁平稳定节点投影树，避免重排时卸载视图；终端继续使用现有 TerminalSessionProvider。最多 16 个工作台分栏，每个终端标签最多 16 叶，复用后台现有 32 活跃会话限制。新增终端为工作区目录的普通 Shell，不复制 Agent 进程。关闭视图继续使用鱼群已有的保留会话语义。

当前关键路径：布局模型与校验 → 两层交互 → 原有功能回归 → 固定候选与独立验收 → 安装与在线验证。

独立核验发现合并 2×20 文件标签会触发旧每栏 32 上限。按可复现缺陷收口：标签预算改为工作台总计 512（16×32），避免合并改变已有标签容量；补充保存/重载及超限拒绝测试。
