# 原始终端历史画面

用户结果：当前 Claude 终端的历史在多次变更尺寸后出现截断和重绘混排。用户可以在同一个鱼群窗口内按当时的列宽回看完整画面，默认适应窗口宽度，也可以按原始字号横向/纵向滚动；当前实时终端继续保留。

关键路径：真实 VT/geometry 前缀复现 → 在尺寸变更前保存完整可见屏幕 → 验证原尺寸阅读 → 固定 renderer 候选与独立核验 → 保留全部后台会话安装 → 原生界面核验。

原始记录不删除、不重写、不伪造。旧滚动缓冲中已经产生的重绘残片保持原样，完整回看通过「历史画面」入口提供；不声称历史中的所有残片已就地修复。Claude 自身输出的省略号也不扩写。画面是尺寸变化前与打开查看器时的可见屏幕，不宣称逐字节录像。显示副本按 4 MiB 序列化文本/最多 200 幅限额保留，若有淘汰明确提示；原始日志不受影响。

实现仅涉及 TerminalView、terminal-replay 的 resize 前回调、新增 terminal-frames/TerminalFrames/样式；不修改 xterm 依赖、不使用试验中的 Windows 配置、不修改 Rust/daemon/Electron 接口。

验收合同：

- 用受影响会话的固定原始字节/47 条尺寸记录复现；185 列的历史帧有完整左右边框，单幅画面无跨次重绘混排。
- 原生 xterm 渲染保存的字符/颜色，实时终端实例不被查看器替换。查看/切换/关闭历史不得发送 PTY 输入。
- 1440/900 宽度下适应宽度、原始字号横向滚动可用；弹层支持 Escape/关闭，原生终端保持可用。
- 单元/回放回归、真实记录浏览器验证及已有终端交互回归通过；生产构建通过。
- 独立核验固定候选、源码/证据/包差异，非 renderer 字节与当前安装完全相同。通过后冻结。
- 安装只重开 GUI/bridge，核验进程身份、会话 ID、DB、历史文件前缀、账号/模型/权限配置保留。原生窗口展示完整历史帧。

证据目录：`artifacts/terminal-history-layout-20261025/`。原始捕获及截图是本地私有验证材料，不发布到远端。
