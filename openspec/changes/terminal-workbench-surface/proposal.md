# 终端纳入唯一前端

用户问“终端呢，是不是也要改”，要求上一轮选择的 A 外观延伸到终端。用户可感知结果：终端与工作台使用协调的底色、选区与清晰字重，搜索/设置/操作在固定工具栏内，不覆盖 Claude/Codex 输出。

仅修改前端容器、终端基本调色板与字重。保留用户字体、字号、行高、光标偏好，ANSI 内容及其颜色、现有会话、输入/粘贴/IME/回放/尺寸协议、后台与账户配置。截图中的 PowerShell 标签是创建该会话的程序身份，不根据终端文本猜测并重写会话类型。

验收：工具栏及搜索栏不覆盖 xterm-screen；边距与画布底色一致；DOM/WebGL、剪贴板、查找与设置焦点、合成输入、会话保留及尺寸/回放测试；构建及打包一致性；安装仅重开 GUI，原 daemon/host/会话保留，实际窗口核对。不把合成 IME 测试当成真实 Windows 输入法 UAT。
