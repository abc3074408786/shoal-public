# 标签栏合并到顶栏

用户要求将 PowerShell / Codex 标签上移，使用刚移除重复标题后空出的顶栏。验收结果应为一行顶栏，终端区域获得原标签栏占用的高度。

复用既有 ChromeTarget 和 TopbarPortal，将容器移入 app-titlebar；保留侧栏按钮、独立窗口拖动区、主题和窗口控制。标签及操作区显式 no-drag，标签可横向滚动；窄窗口保持窗口按钮可见。分屏继续保留每个 pane 的标签栏。

不修改终端内容、输入、会话、模型、权限和后台生命周期。安装只更新 renderer 并重开 GUI/bridge，保留全部 CLI 与宿主进程。

验收：900/1100/1440 宽度下单行布局，无横向越界；标签切换、菜单、侧栏、分屏/合并正常；连续切换保留终端实例和已消费偏移；正式窗口实测同一行显示标签，空白处可拖动窗口，当前内容与会话保留。技术通过不替代用户视觉验收。
