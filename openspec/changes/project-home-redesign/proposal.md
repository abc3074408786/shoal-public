# Searchable project home

The current homepage uses a large centered greeting and glass tiles. The user requested a redesign and confirmed that existing projects and new projects are equally important.

Use the established desktop identity with a compact searchable project list and always-visible open/create actions. Keep original project callbacks and order; display only factual name/path/type data. Do not change the runtime, terminal behavior, saved settings or project storage.

The concrete candidate is built and rendered in `artifacts/project-home-redesign-20261102`. Owner visual review precedes installation; technical checks do not imply visual acceptance.
