# 工作树创建与执行主机

## 目标

在唯一 WorkspaceApp 中补齐项目默认 Git 基准、创建时 setup、组织性父子关系、原生 Agent 模型/推理强度/初始提示词，以及通过 SSH 管理 Linux 和 Windows 远端工作树。

## 已批准边界

- 沿用当前界面、主题和原生终端，不恢复已删除界面，不增加结构化聊天。
- 保留现有未提交修改、所有正式 profile、工作树及会话；不执行安装、发布、提交或推送。
- 父级只决定组织关系，不决定 Git 基准、权限或文件复制。
- 项目默认基准按显式值、项目配置、只读推断解析；首次接受请求冻结 OID。无有效或唯一候选时拒绝。
- 旧项目普通创建默认跳过 setup，受管入口保留原来的执行选择；未知历史批准不得伪造。
- 创建记录先保存意图，再执行 checkout/setup/launch/prompt；请求内容冲突拒绝，未知结果不重放。
- TaskSpec.launch 是默认空的窄类型；模型/effort 缺省继承目标 CLI 配置，保留审批与沙箱。
- SSH 使用系统 OpenSSH、严格主机密钥和非交互认证；远端 runtime 预先安装，不上传凭据/代码，不开放 RPC 端口，不回落本机。
- 远端身份、项目路径、会话与所有异步请求绑定目标。SSH 中断不应停止远端 daemon/PTY。
- Windows SSH 进程持续性不足时要求独立启动远端 runtime，不擅自安装服务或计划任务。

## 交付顺序

1. 合同、迁移、创建操作记录和父级事务。
2. 本机统一创建、setup、参数与提示词回执、工作台控件。
3. 主机注册、SSH 有界帧协议、remote-stdio、目标路由与恢复。
4. 外围能力边界、浏览器/Electron 回归及 Linux/Windows 真实 SSH 验收。

## 远端矩阵

支持项目/工作树、setup、Agent、原生终端、文件、Git 与任务验证。远端首版禁用 clone 向导、资源监控/清理、图片粘贴（终端仅文本粘贴）、浏览器/browser-agent、编排/自动化/任务来源页面；本机功能保留。评审检查的目标端只读实现尚未落地，远端为渲染层与主进程双重拒绝，不以任何本机结果代替。

## 验证

2026-11-12 新增经用户批准的 MiniMax 原生终端与本地项目/远程 Codex 模式，分别见 [minimax.md](minimax.md)、[hybrid.md](hybrid.md)。hybrid 的生成 relay/config 传输例外仅适用于新模式，不改变既有远端工作区的边界。

分别记录 Rust/JS 单测、fixture、真实 runtime、浏览器/Electron、真实 CLI、双系统 SSH。使用隔离数据目录和测试进程，不连接生产 profile。真实 SSH 条件不足则标记未验证，不以 mock 或成功 spawn 替代持续运行证明。
