# 本地项目与远程 Codex

用户于 2026-11-12 批准本模式。项目和 Git 主副本仍在本机，远程 Linux 运行 Codex、原生命令和计算服务。远程 Codex 通过会话专用 MCP 工具访问选定本机项目。

此模式允许向远端新建私有临时目录传输生成的 relay/config，不自动上传项目或账号凭据。它是原有“远端工作区”的独立模式，原来的路由、身份验证、禁用项和不回落本机规则保留。

本机读取限定项目根目录；本机写入需要内容摘要和审批；本机命令需展示目标主机、cwd、程序及参数并审批。审批不是操作系统沙箱。请求绑定工作区、会话、SSH 配置摘要和请求 ID，日志记录操作位置和结果。拒绝越界路径、链接逃逸、错误会话与过大协议帧。

断线和超时后不自动重放写入或命令，结果不明时显示“未知”。恢复只继续同一远程原生会话。界面关闭不终止已有 host/PTY；明确停止按会话关闭桥接。

隔离验收需要证明：远程 Codex 读取/修改本机测试文件并取得本机命令结果，远程命令输出 Linux 资源信息；冲突、拒绝和断线不会重复执行。候选包和正式安装、当前在线、业务 UAT 分别记录。

## 并行编排范围变更（2026-11-13）

用户要求远程 Codex 作为现有多 Agent 编排成员，与其他成员并行工作。每个成员使用现有编排分配的本机隔离工作树；SSH 配置、会话、协作成员和任务尝试必须绑定。远程侧通过会话专属受控通道使用本机工具及本成员的协作能力，不能获得其他成员的凭据或自行扩权；本机写入与命令仍逐项审批。角色的只读和写入边界、独立审查、集成、验证与无自动重放要求保持不变。每个节点的变更只进入其工作树，依既有规则审查并集成，原项目仍为主副本。

验收必须证明远程 Codex 与至少一个其他成员实际并行、任务身份与隔离工作树正确、经过本机审批的任务成果和审查/集成证据完整；并发冲突、越权、连接中断与不重放另作验证。不得以终端成功启动或本机 mock 代替实际并行验收。

## 模型后端确认（2026-11-13）

用户确认继续使用远端 Codex CLI，模型后端为 DeepSeek；不改为 OMP/OpenCode。当前远端配置的模型为 deepseek-flash，provider 为 custom，使用回环地址上的 Responses 网关，requires_openai_auth=false；以上为配置及监听探测，不是模型请求验收。

远程角色必须冻结并核验选定的 provider/model，不得套用本机 Codex 角色的 Terra/Luna 默认值。网关认证材料只允许在远端原生进程内解析和注入，不写入本机计划、任务、角色快照或日志。缺失、变化或不支持的 provider 配置必须在模型调用前失败，不回落到其他模型或本机。

本次不安装其他 Agent CLI，不继续扩展 ChatGPT 认证文件挂载方案。既有本机工具审批、工作树、身份、审查集成、断线不重放及真实并行验收标准保持不变。

受控会话的技能预检和原生执行使用同一独立 HOME/CODEX_HOME，不继承全局原生配置。模型凭据在切换环境前只在远端内存中解析，随后仅注入模型进程；禁止传给本机快照、原生 shell 或会话 MCP。受控 exec 不注册身份 Hook，以完整结构化原生事件和成功退出回执绑定会话并验证继续身份。

探索角色可通过逐项审批的 local_write_evidence 新建 .velella/evidence/<UUID>.log，仅用于提交实际核验记录。该工具不接收自定义路径、不覆盖已有文件、不赋予源码写入或本机命令权限；证据身份检查与独立审查仍由原编排承担。
