# 编排会话直达与执行优先

用户批准借鉴 Orca 的工作区内直接工作方式，保留 Velella 自有外壳。

结果：新建协作出现自有会话后直达一次；起草前的信任等待也有会话入口；返回编排保留选中协作；运行态优先显示执行信息，配置仍可编辑。

验收：会话入口使用后端返回的 workspace/session 身份，不猜测；新建只自动导航一次；历史协作不因轮询抢焦点；无会话时说明尚未启动；浏览器回归和前端构建通过。真实 CLI 与总体交付验收另行进行。

续接实现：会话先在同页弹层展示并支持展开工作台；创建前只读检查 Git 提交、归档、数据目录重叠，提交时后端重新校验；使用现有主题收紧标题、标签和步骤间距。不会自动初始化或提交用户仓库。
